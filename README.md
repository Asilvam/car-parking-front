# Minuto — Frontend

Frontend tradicional construido con React, TypeScript y Vite.

## Requisitos

- Node.js 20.19+ o 22.12+
- Backend disponible en `http://localhost:3500`

## Configuración

```bash
cp .env.example .env
npm install
npm run dev
```

Para usar otra URL del backend:

```env
VITE_API_URL=http://localhost:3500
```

## Comandos

```bash
npm run dev
npm run build
npm run preview
npm test
```
